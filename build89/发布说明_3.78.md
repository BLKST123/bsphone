## Prompt 与 Token

- Prompt 分为稳定设定、半静态规则、滑窗历史、动态时间/最新输入。
- 历史同时受消息条数和估算 Token 预算限制。
- 解析 OpenAI/兼容站 `usage` 与 Gemini 风格 `usage_metadata`、`cached_content_token_count`。
- 聊天页显示本次输入/输出/缓存命中，设置页显示累计 Token 与缓存。
- 429、5xx 和网络错误使用指数退避和可取消等待。
- API Key 从主数据库剥离，使用 IndexedDB 中的非导出 AES-GCM 密钥加密保存。
