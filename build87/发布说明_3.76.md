# BS小手机 3.76（versionCode 87）

## 复检修复

- APK 完整打包 `core/store/core-store.js` 与 `core/store/readonly-store.js`。
- 安卓原生网络改为异步 requestId + 工作线程，不再阻塞 WebView 主线程。
- 原生网络支持 `cancel(requestId)`，网页超时和用户取消会同时断开 HttpURLConnection。
- 聊天请求发网前等待一帧绘制，确保“正在输入”先显示。
- 启动时断言 `BSCoreStore.ready()` 与 `BSReadonlyStore.ready()`，缺失时在自检和页面提示。
- 打包门禁会检查 index 引用的全部本地脚本和资源，不再只比较 index.html。
- 原生键盘高度改为读取真实 IME Insets，键盘弹起时不再重复压缩页面。
- 保留本地数据地址与签名，可直接覆盖升级。

## 安装包

- `BS小手机_3.76.apk`
- 最终 SHA-256 在构建完成后写入 `SHA256.txt`。
